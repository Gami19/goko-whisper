## 調査まとめ｜歴史的背景

### 旧第五高等学校（五高）とは

| 項目 | 内容 |
|------|------|
| 設立 | 1887年（明治20年） |
| 正式名称 | 第五高等中学校→第五高等学校 |
| 役割 | 明治政府が全国に設立した旧制高等学校のひとつ |
| 廃校 | 1950年（熊本大学設立と同時に発展的解消） |
| シンボルカラー | **紫（菖蒲色）** |
| 愛称 | **紫熊**（熊本大学の学園祭名の由来） |

### 五高ゆかりの人物（UIの物語に直結）

| 人物 | 在任期間 | 備考 |
|------|--------|------|
| **ラフカディオ・ハーン（小泉八雲）** | 1891〜1894年 | 五高で英語を教えながら熊本滞在中に「怪談」の素材を収集。「囁き」との親和性が非常に高い |
| **夏目漱石** | 1896〜1900年 | 八雲の後任として赴任。後に「草枕」「坊っちゃん」を執筆 |

### 五高記念館について

| 項目 | 内容 |
|------|------|
| 建設年 | 1889年（明治22年） |
| 建築様式 | **ルネサンス様式・木造二階建て** |
| 外観 | 白い下見板張り・赤い屋根・アーチ型窓 |
| 指定 | **国重要文化財**（1965年指定） |
| 現在 | 熊本大学キャンパス内に現存・一般公開 |

### 熊本大学の成立

```
1887年  五高（第五高等中学校）設立
  │
  │  ← 漱石・八雲が教壇に立つ
  │
1950年  熊本大学 設立（五高を主要前身校として統合）
  │
現在    紫熊祭（五高の「紫熊」の名を冠した学園祭）
```

## 「囁き」の世界観｜ブラッシュアップ

### 小泉八雲との接続

> 八雲は熊本在住中、地元の人々から耳にした言い伝えや記憶を丁寧に拾い集め、**怪談**として世界に伝えた。
> 「囁き」とは、まさに八雲が聞いたものと同じ——**記憶が声になる瞬間**である。

このコンセプトを軸にすることで、スタンプラリーが単なるゲームではなく**「八雲が聞いた声を、あなたも聞く」という体験**になる。

## 囁きの言葉（文面案）

### 第一の囁き

```
耳を澄ませ。

この街の風は、まだあの頃の声を運んでいる。
```
> 八雲が熊本の街を歩きながら声を集めていたイメージ

---

### 第二の囁き

```
灯は、消えない。

学んだ者の記憶が、石となり、壁となり、
今もここに立っている。
```
> 五高記念館の建物そのものが「記憶の結晶」であるイメージ

---

### ゴール（五高記念館で二つが完結する一文）

```
あなたは今、
百年前の声が聞こえた場所に立っている。
```

## タイポグラフィ｜ブラッシュアップ

| 用途 | フォント | 理由 |
|------|--------|------|
| 囁きの言葉 | 游明朝・ヒラギノ明朝・serif | 明治の文語体のような格調 |
| タイトル「五高の囁き」 | 同上・細めのウェイト | 繊細・静謐 |
| 説明・誘導文 | 游ゴシック・ヒラギノ角ゴ | 読みやすさ優先 |
| 認定コード・タイマー | 等幅システムフォント | 視認性・緊張感 |

### 文字表現のルール

```
囁きの言葉  ： 縦書き を検討（明治・和の雰囲気を強調）
              ただしスマホ横幅で無理なければ
誘導テキスト： 横書き・小さめ・行間2倍
固有名詞    ： 「五高」「八雲」などは菖蒲色で強調
```

## アニメーション｜ブラッシュアップ

### 1. 囁き出現（メイン演出）

```
【変更点】
旧：金色のフェードイン
新：菖蒲色・霧の中から浮かぶ

① 0.5秒 ── 画面が完全な暗闇
② 2.5秒 ── 文字が霞の奥から浮かび上がる
           ぼやけ（blur）→ くっきり
           広い字間 → 通常字間
           透明 → 不透明
           色：暗い紫 → 菖蒲色 へ変化

【印象】 八雲が耳にした声が、霧の中から現れる感覚
```

---

### 2. 五高記念館シルエット浮上

```
【ゴール画面限定】

① 最初は完全に透明
② 30秒かけて　透明 → 白磁色10%　にゆっくり浮かぶ
③ 建物の輪郭線が先に現れ、内部の陰影が後からにじむ

【シルエットの特徴を再現するSVGのポイント】
・アーチ型の窓（ルネサンス様式）
・左右対称の二階建て外観
・屋根の三角形のペディメント
・白い下見板張りの壁の縦縞

【印象】 記憶の中から建物が甦る感覚
```


## 物語の流れとUIの対応

```
[トップ]
  背景：暗い紫黒・静寂
  役割：旅のはじまり・ニックネームを刻む
       ↓
[第一の囁き]
  背景：暗い紫黒・霧のテクスチャ（CSSのみ）
  役割：八雲の声・街の記憶
  色調：菖蒲色メイン
       ↓
[第二の囁き]
  背景：暗い紫黒・少し明るくなる
  役割：五高の声・建物の記憶
  色調：薄明紫メイン
       ↓
[ゴール]
  背景：最も明るい・記念館シルエットが浮かぶ
  役割：到達・二つの声が完結する
  色調：白磁・深緋で達成感を演出
```

## 五高記念館SVGシルエットの設計方針

```
・建物の特徴を最低限の線で表現
・アーチ型窓を最も目立たせる（ルネサンス様式の象徴）
・色は白磁（#EAE4DA）・透明度10〜20%
・背景に溶け込む程度に留める（主役はテキスト）
・ファイルサイズ3KB以下を目標
```
