## タイポグラフィ

### フォント選定（Webフォント不使用・端末フォントのみ）

| 用途 | フォント指定 |
|------|------------|
| タイトル・囁きの言葉 | 游明朝 → ヒラギノ明朝 → serif |
| 本文・説明文 | 游ゴシック → ヒラギノ角ゴ → sans-serif |
| 数字（タイマー・コード） | システムの等幅フォント |

> **明朝体** で歴史と静けさ、**ゴシック体** で現代の読みやすさを使い分ける

### 文字サイズの考え方

```
タイトル（囁きの言葉）  ：大きく・中央配置・行間を広めに
説明テキスト           ：小さめ・控えめ・上下に余白
ニックネーム           ：やや大きく・金色で強調
タイマー数字           ：等幅・やや大きめ・画面中央
```

## 画面ごとのデザイン詳細

### ① トップ画面（ニックネーム入力）

```
┌─────────────────────────┐
│                         │
│                         │
│   五高の囁き             │  ← 明朝体・金色・小さめ
│                         │
│  ━━━━━━━━━━━━━━━━━      │  ← 細い金の横線
│                         │
│  あなたは、五高の声を    │  ← 明朝体・古紙色・中央
│  聞いたことがありますか。│
│                         │
│  ━━━━━━━━━━━━━━━━━      │
│                         │
│  [ お名前を入れてください ]│  ← 入力欄（枠なし・下線のみ）
│                         │
│                         │
│      ▷ 旅を始める        │  ← ゴシック体・金色・下線
│                         │
└─────────────────────────┘
```

**デザインポイント**
- 余白を大きく取る（圧迫感なし）
- 入力欄は四角い枠ではなく**下線のみ**（ミニマル）
- ボタンはテキストリンク風（装飾を最小限に）
- 背景は**完全な黒に近い色**一色

- ボタンを押す前後で**画面の雰囲気が変わる**演出

- カウントダウンは**赤みを帯びた色に変化**（残り1分を切ったとき）

## アニメーション一覧

### 1. 囁き出現アニメーション（メイン演出）

```
【動き】
① 画面が暗いまま 0.5秒 静止
② 文字が　ぼやけた状態・広い字間　から始まる
③ 徐々に　くっきり・通常字間　に収束する
④ 同時に　透明→不透明　にフェード

【印象】　霧の中から言葉が現れてくる感覚
【時間】　約 2.5秒
【使用箇所】　スタンプ取得画面の囁きテキスト
```

---

### 2. 画面遷移アニメーション

```
【動き】
① 現在の画面が　下から上へ　暗くなりながら消える
② 次の画面が　上から下へ　明るくなりながら現れる

【印象】　古い本のページをめくる感覚
【時間】　約 0.4秒
【使用箇所】　全画面遷移
```

---

### 3. スタンプ取得エフェクト

```
【動き】
① ボタンを押すと　画面中央に円形の光　が広がる
② 光は蝋燭金色→エメラルド色に変化しながら消える
③ 「刻まれた」の文字がフェードイン

【印象】　蝋燭の灯が一瞬揺れて安定する感覚
【時間】　約 1.5秒
```

---

### 4. ゴール画面の演出

```
【動き】
① 背景に記念館シルエットがゆっくり浮かび上がる（3秒）
② ニックネームが上からフェードイン
③ コード番号が　一桁ずつ　カウントアップして確定
④ カウントダウンタイマーが静かに始動

【印象】　長い旅が終わり、扉が開く感覚
【時間】　演出全体で 約 4秒
```

---

### 5. カウントダウン警告アニメーション

```
【通常時】  白色・静止
【残り2分】 黄色に変化
【残り1分】 赤色に変化 ＋ 数字がゆっくり点滅

【印象】　緊張感・急かしすぎない程度の警告
```

## インタラクションの細部

| 操作 | 反応 |
|------|------|
| ボタンタップ | 軽い振動フィードバック（Vibration API）＋光のエフェクト |
| スクロール | なし（全画面1ページ構成・スクロール不要） |
| 誤操作（戻るボタン） | 「この旅を中断しますか？」の確認を表示 |
| 通信エラー | 「囁きが届かない…」のメッセージ（エラー感を和らげる） |

---

## 全体の統一ルール

| ルール | 内容 |
|--------|------|
| 角丸 | **使わない**（直線的・硬い印象で歴史感を出す） |
| 影 | **使わない**（フラットに徹する） |
| アイコン | **使わない**（文字と線のみ） |
| ボーダー | 細線（1px以下）・金色か煤色のみ |
| 余白 | **大きめ**（窮屈にしない） |
| 動き | 速すぎず・派手すぎず（「静かな演出」を貫く） |
